# Obsidian Memory Notes

Obsidian vaults are read-only source truth. ContextForge should extract headings,
frontmatter, tags, and wikilinks such as [[Source Refresh Policy]] without
rewriting the vault.

#agent-memory notes can mention Hermes preferences, project status, and links
between ideas. The phrase "vault backlink context" is used for Obsidian metadata
checks.

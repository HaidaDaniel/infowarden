# Contributing

Use Node 22–24 and pnpm 10.30.3. Install with `pnpm install --frozen-lockfile`,
then run `pnpm prisma:generate`, `pnpm typecheck`, `pnpm build`, and `pnpm test`.
Keep changes focused and include tests for changed behavior. Do not commit
credentials, personal collections, or deployment data. Benchmark fixtures and
frozen results must not be relabeled or overwritten to improve scores.
